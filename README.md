# VOGE · Yeray Santos

Carpeta preparada para publicar directamente con GitHub Pages.

## Contenido

- `index.html`: página principal completa.
- `.nojekyll`: indica a GitHub Pages que publique los archivos directamente.

El logotipo y los demás recursos visuales ya están integrados en `index.html`,
por lo que no hacen falta archivos PNG adicionales.

## Publicación

Sube todo el contenido de esta carpeta a la raíz de un repositorio de GitHub.
Después, abre `Settings > Pages` y selecciona:

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/(root)`

No elimines ni cambies el nombre de `index.html`.
